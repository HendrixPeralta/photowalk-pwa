# PhotoEYE

Plan photo walks, learn composition, and keep a reference library.

- **App:** [`web/`](web/), React, Next.js and TypeScript. Live at https://photoeye-wine.vercel.app (Vercel deploys `main`).
- **Review sheet backend:** [`tools/review-endpoint.gs`](tools/review-endpoint.gs), the Google Apps Script the review form posts to.

The original vanilla-JS version lives on the `master` branch and stays online at
https://hendrixperalta.github.io/photowalk-pwa/ (GitHub Pages builds it from `master`).
